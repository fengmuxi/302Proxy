      安全与封禁

      查看封禁名单、配置自动封禁策略与白名单。

      封禁规则说明：IP 封禁只拦截代理转发路径（命中路由组 / 规则的请求），不影响后台管理（/_admin）及系统内置接口（/_health、/json/version、/_block）的访问，被封禁的 IP 仍可正常打开后台。
      「路径前缀」留空 = 全局封禁（拦截该 IP 的所有代理请求）；填写如 /play = 仅拦截该前缀下的代理请求。
